Technical Notes

The following JavaScript code demonstrates a simple function: 


function calculateTotal(items) {
  return items.reduce((sum, item) => sum + item.price, 0);
}

const total = calculateTotal([
  { price: 100 },
  { price: 200 },
  { price: 300 }
]);

console.log(total);

The above example is frequently used in technical documentation and API guides.
